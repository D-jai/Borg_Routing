API Keys

Configure external model providers. Keys are stored in your local .env file — never sent off-device.

OpenRouter (recommended — access to 200+ models)

How it works: OpenRouter keys are written to .env as OPENROUTER_API_KEY=… (the canonical env var read by discovery, the scorer, and chat completions). Custom providers fall back to KEY_{NAME}=… and ENDPOINT_{NAME}=…. After saving, run Discover Models on the Models page to pull in this provider's model list and pricing.
