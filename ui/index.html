BORG_ROUTE UI Index

BORG_ROUTE

Adaptive Recursive Agent Router. Pick a surface below, or use the API directly at /health, /v1/chat/completions, /runs, /models/matrix.

Chat

Send a single prompt to BORG and watch it orchestrate a response.

Models

Discover models, run capability research, tick rows into the routing pool.

API Keys

Store and manage provider keys (OpenRouter, Tavily, custom endpoints).

Run Trace

Inspect a single run's envelopes, events, and failure reason.

Logs

Browse the rolling event log across all runs.

Dashboard

Cost, tokens, and run counts over time.

Skills

View the pre-written skill catalogue (prompt templates).

Admin

Governance rules ledger and router knobs.
Not sure where to start? The Models page is step one on a fresh install: discover → research → tick at least one row. Then use Chat.
