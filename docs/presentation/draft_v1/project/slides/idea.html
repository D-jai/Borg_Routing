BORG_ROUTE works like a project manager.

Plan

Splits the job

A planner model breaks your request into steps and labels each one: what kind of work it is and how hard.

Route

Picks who does each step

Each step goes to the cheapest model in your pool that is good enough for it. A model on your own machine has no token price, so it wins whenever it qualifies.

Show

Hands you the receipt

Every answer lists which model did each step, why it was chosen, how long it took and what it cost.
