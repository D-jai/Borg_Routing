# Error Registry — BORG_ROUTE
> Format: `BRT-[MODULE]-[NNN]`
> Modules: REG, ENV, DB, PIP, ORC, APE, TOOL, SKL, SOP, ANS, LOG, API, ADM, MEM, LANE
> Every code raised or logged in `src/` has a row; a row for a code no longer in the code is marked retired.

| BRT-REG-016 | Speed probe of a local model failed | `src/registry/throughput.py::measure_throughput` (in the background after `POST /models/discover` and `PATCH /models/{id}/checked`; at the start of a top-level run, `src/orchestrator/engine.py::_measure_local_speeds`, which also writes an `error` event with severity warning, the code and the model id; at bench stage start, `bench/run_bench.py`) | Logged, not raised. | BRT-REG-031 | Scorer response unparseable | `src/registry/scorer.py::_parse_scores` | The scoring LLM returned content that is not JSON. Most often happens when `SCORING_MODEL` is a model that cannot web-search. Switch to `perplexity/sonar-pro-search` or another search-enabled model. |
| BRT-REG-032 | curated_models.yaml missing or malformed | `src/registry/discovery.py::_load_curated_ids` | `data/curated_models.yaml` is absent, not a YAML list, or empty. Restore the sample file and list up to ~12 OpenRouter model IDs (`- id: <openrouter-id>`). |
